# physics0

Foundation0's physics research, done the Foundation0 way: in the open, with every claim backed by something a
machine can check, and credited to the people and the AI models that did the work.

## Studies

| study | question | status |
|---|---|---|

## How results are checked here

- **Certificates, not screenshots.** A numerical claim comes with a file a short verifier can re-check, and
  where possible with two verifiers that share no code.
- **Negative controls.** Verifiers are tested on corrupted certificates and must reject them.
- **Plain status labels.** Each study says what is proved, what is computed, what is only evidence, and who
  has (or has not) reviewed it.
- **Credit.** Prior work is cited where it is used. Each study records which AI model did what.
